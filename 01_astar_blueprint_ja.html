A* の設計図

どこで点を取れば A* に届くか。シラバスの配点と Examiner Report の指摘から、A* を取る答案の習慣を整理する。

🧭 1. 評価観点(AO)の配点を知る

A* に必要なのは、配点の重い AO で確実に点を取ること。シラバスの数値を整理する。

IGCSE 0478 試験構成

AS A Level 9618 試験構成

試験内容時間・配点AS / A Level への比重AO1 / AO2 / AO3
Paper 1Theory Fundamentals(Sec.1–8)1h30・75点AS 50% / A 25%60 / 40 / 0
Paper 2Fundamental Problem-solving and Programming Skills(Sec.9–12)。pseudocode で解答2h・75点AS 50% / A 25%0 / 40 / 60

Paper 4Practical(Sec.19–20)。Java / VB / Python、インターネットなしでPC上で解答2h30・75点A 25%0 / 0 / 100

全体(AS):AO1 30% / AO2 40% / AO3 30%。全体(A Level):AO1 30% / AO2 30% / AO3 40%。出典:9618 シラバス 2026。

A Level の重要な事実: AO3(40%)は P2(25%×60% = 15%)と P4(25%×100% = 25%)だけで構成される。つまり A Level の最重要の観点は、 プログラミングと問題解決の2つの試験(合計 50%)にある。理論(P1・P3)で満点近くを取っても、P2・P4 が弱いと A* には届きにくい。
IGCSE も同じ構造: P2 の AO2 が60%(アルゴリズムの設計・適用)。 15点シナリオは P2 の20%にあたり、最も点差がつく1問。

⭐ 2. A* を取る答案の6つの習慣(Examiner Report が示すもの)

各項目は、Examiner Report が高得点の条件、または失点の原因として繰り返し挙げている点(出典付き)。

① context に結びつけて書く

シナリオの名詞(sensors の種類、tractor、search engine など)を答えに入れる。

0478 ER Mar 2024 P12 / Mar 2025 P12 / Jun 2026 P11–13 / 9618 ER Jun 2025 P31

② command word と点数に答えを合わせる

explain は「どのように/なぜ」まで。点数分の異なるポイントを書く(同じ内容の言い換えは1点)。

0478 ER Jun 2025 P22–23 / 9618 ER Jun 2025 P11–13, P31–33

③ 専門用語を正確に使う

日常語ではなく、syllabus の用語で。「computer が instruction を execute する」のように動詞も正確に。

0478 ER Jun 2026 P11 / Mar 2026 P12 / 9618 ER Jun 2025 P11–13

④ pseudocode は CIE 形式で完全に書く

END 系の文、file mode、CLOSEFILE のファイル名、予約語を避ける。変数宣言・初期化も書く。

9618 ER Jun 2025 P22–23 / 0478 ER Jun 2025 P22–23

⑤ 書く前に設計する

ループの種類、引数、データ型、IF か CASE かを先に決める。シナリオは最後まで読む。

9618 ER Jun 2025 P23 / 0478 ER Mar 2024 P22

⑥ 作業を見せる

計算問題は working を書く(部分点が出る)。trace table は途中の値を省略しない。

9618 ER Jun 2025 P31–33, P31 Q2(b)

🔬 3. A* と A を分ける要素

観点A 止まりの答案A* の答案
理論(P1/P3)正しいが generic。点数より少ない数のポイントcontext に結びつけ、点数分の独立したポイントを書く
pseudocode(P2)ロジックは正しいが END 文・file handling に1–2箇所の誤り構文ミスがゼロ。設計(ループ・型・引数)が先に決まっている
P4 実技プログラムは動くが、evidence document の体裁やテストが不完全全 input/output のスクリーンショット、indentation 維持、header 記載、各小問の正しい位置
0478 15点問題題意の一部を実装scenario の全項目を満たし、与えられた変数を使い、コメントを書く
用語日常語を混ぜるsyllabus の用語と動詞を正確に使う
grade threshold(合格点・A*の点数)について: A*/A の境界点はシリーズごとに Cambridge が公開する grade threshold で決まる。このガイドには特定の値を載せていない。 目標点数を決める場合は、直近シリーズの公式 grade threshold を確認して差し込むこと。
