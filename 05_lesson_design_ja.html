05 ・ 授業の型と毎週の回し方

授業設計(80分×週3回)

説明を授業の外へ出し、授業は「引き出す・書かせる・直させる」に使う。3つの授業の型と、毎週の準備・採点の回し方。

🎯 1. 設計の原則

授業時間が足りない中で点を上げるため、「説明」ではなく「引き出す・書かせる・直させる」に時間を使う。

  • 初回の説明は授業の外へ:NotebookLM教材・Study Guide・動画で事前学習 → 授業の頭に3問の確認テスト。授業は「つまずきの解消」と演習。
  • 毎回、試験の言葉で書かせる:command word・context・専門用語を意識した1問を必ず書く(00 の原因①②)。
  • プログラミングは紙が先:pseudocode は手で書き、構文チェックリストで自己採点(原因③)。
  • 間隔を空けて引き出す:毎回の最初に、先週・先月・前学期の内容から2〜3問。
  • 直しまで授業内で:mark scheme と見比べて書き直す時間を授業に組み込む。

⏱ 2. 80分授業の3つの型

AS・A2 は週3コマ(80分×3)。IGCSE は80分×2 + 40分(3節)。

時間A 理論回(週2コマ)B プログラミング回(週1コマ)C 試験演習回(月1回、A または B を置き換える)
0–10分引き出しクイズ3問(先週・先月・前学期から)+ 事前学習の確認3問pseudocode 構文クイズ(END 文・file handling・予約語)ルールの確認:時間配分、command word、見直しの手順
10–25分誤概念の提示(正誤判定)+ つまずきの解消(教員が説明するのはここだけ)新しい構造の worked example(教員が声に出して設計)過去問のセクション(AS P1・P2、A2 P3・P4、IGCSE P1・P2)を、本番の制限時間で解く。P4 は PC で evidence document を作成
25–55分試験形式の問題を書く(ペア → 個人)。command word と点数を指定課題:紙で pseudocode → PC で確認
55–70分mark scheme と見比べ、書き直す(答えを見て直した部分に印をつける)trace table で自分のプログラムを検証、ペアレビュー
70–80分出口チケット:1問(command word 指定)を書いて提出出口チケット:今日の構文の確認 + エラーの記録自己採点 → 失点を4分類(00)
週の組み立て(AS・A2): 月曜 = A(新内容)、水曜 = B(プログラミング)、金曜 = A(演習と直し)。月1回、金曜を C にして過去問を時間通りに。

IGCSE の週3節(80分・80分・40分)

節内容
80分(1)理論 or プログラミングの新内容。前半に10分の引き出しクイズ、後半に試験形式の問題を1問
80分(2)演習と直し。G9 は context 付き記述問題、G10 は pseudocode と trace table(紙で)
40分引き出し(G9 内容を G10 まで保持させる)+ command word の訓練 + 過去問の小問1つ

📝 3. 毎週の準備(教員)

作業時間の目安内容
授業の準備約45分A 回の誤概念リスト(Examiner Report から2〜3個)、試験形式の問題を選ぶ(過去問・Topical practice papers)
B 回の課題約20分課題を1つ選び、自分で解いて、出やすい構文ミスを予想
採点とコード付け約45分出口チケットを採点(下の誤りコードを付ける)。全員の点数ではなく、誤りの種類を集計
集計と翌週への反映約10分最も多かった誤りコードを、翌週の引き出しクイズに入れる

合計約2時間。必要に応じて調整。採点は全員を毎週ではなく、半数ずつ交互に行ってもよい。

誤りコード(00 の4原因に対応)

コード意味例
CContext・command word の不一致(原因①)explain に describe で答えた/generic な答え/例示された答えを繰り返した
T専門用語・誤概念(原因②)「understand instructions」/ 1 KiB = 1000 bytes
S構文・プログラミングの細部(原因③)ENDIF 欠落/CLOSEFILE にファイル名なし/予約語
K未習・知識不足(原因④)内容を知らない
Wworking・trace の省略計算の途中を書かない、trace table の途中の値がない
X重複・除外同じ内容の言い換え、除外された答え

📚 4. 宿題の3層設計

毎週:引き出し(10分)

用語・定義・誤概念の正誤。自動採点できる形式(Revision Guide・Study Guide のクイズ)。

隔週:試験形式の1問(20分)

command word と点数を指定した記述問題(IGCSE 4–6点、AS・A2 6点)。mark scheme で自己採点し、誤りコードを付ける。

毎月:プログラミング・過去問(60–80分)

P2 の1問(紙)、P4 の1小問(PC)、0478 の15点問題など。evidence document の作法も含む。

📲 5. AS・A2 の事前学習(時間不足を補う)

  • NotebookLM Content(章ごとの学習資料)を事前学習に指定。目安は1回20〜30分。
  • 授業の頭の3問で、事前学習をしたかを確認(未実施の生徒は授業内の個別支援へ)。
  • 事前学習は、新内容の定義・手順・例まで。応用・試験の書き方は授業で扱う。
  • AS・A2 は想定時間の58–71%しか授業がないため、この仕組みがないと内容が終わらない(00 を参照)。
