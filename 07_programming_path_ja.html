🧭 1. なぜプログラミングが中心か

配点から見ると: A Level の AO3(40%)は P2 と P4 だけから来る(01)。IGCSE は P2 の AO2(60%)。 いずれの試験でも、Examiner が最も多く失点を指摘しているのは pseudocode の構文と設計(00 の原因③)。
学年試験で求められること使う言語

G10P2:short-answer は pseudocode のみ。15点シナリオは pseudocode または Python / VB / Javapseudocode(紙) + Python(15点問題と実行確認)
G11P2:pseudocode で解答(2時間)pseudocode(紙) + Python(動作確認)
G12P4:Java / VB / Python(console)で実装、テストの証拠を提出Python など1言語に固定(練習量を集中させる)

出典:0478 シラバス(4章 Details of the assessment)、9618 シラバス(Assessment overview)。

🧪 3. 設計・テスト・デバッグの指導

書く前の設計メモ(2分)

  • 入力・出力・使う変数(型)は?
  • ループは count-controlled か conditional か?
  • IF の連続か CASE か?
  • 関数・手続きの引数と戻り値は?
9618 ER Jun 2025 P23 Key messages

テストデータ

  • 通常・境界・不正の3種を選ぶ
  • 問題文のテストデータの条件(rubric)を読んでから選ぶ
  • 「State a value」には変数名ではなく値を書く
  • 最大・最小を求める処理は、最初の値が最大/最小の場合もテスト
9618 ER Jun 2025 P21 / Nov 2025 P41

デバッグの手順

  • エラーメッセージを読み、行を特定
  • 期待値と実際の値を trace table で比較
  • 構文ミス(END 文・引用符・予約語)から先に確認
  • 1つ直すごとに実行
